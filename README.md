# Pulse Lite

A real-time patient vitals monitor — single patient, single user, built deliberately.

I'm rebuilding my fundamentals while shipping this project. Strict rule: no
AI-generated code on first attempts. Every line is mine. Claude Code acts as a
Socratic teacher — hints only, never code.

This repo is public as accountability. Daily commits with explanatory messages
are the discipline.

## Stack

- TypeScript + Express + Postgres (backend)
- React + TypeScript + Vite (frontend)
- WebSockets for real-time vitals streaming
