Ranked Gaps (weakest first)

1. SQL & Data Modeling — Zero functional knowledge. No awareness of joins, aggregation, keys, or normalization. This is a hard blocker for any backend or full-stack work.

2. TypeScript — Nearly no working knowledge beyond a vague sense that any means "any type." Generics, keyof, readonly, and interfaces are all unknown. Blocks working in any modern TypeScript codebase.

3. System Design — No vocabulary for distributed systems (scaling, load balancing, CAP). The monolith/microservices definition was confused with file organization rather than deployment and communication models.

4. JavaScript Core — The most foundational topic and still shaky: typeof null, closures, the event loop, and async execution order were all wrong or unknown. These are prerequisites for everything else.

5. React Internals — Some surface exposure (useEffect deps, key prop) but virtual DOM, reconciliation, and controlled components are missing. Practical React work will hit walls quickly.

6. HTTP & Web Fundamentals — The best-performing topic, but still thin. CORS, cookies vs storage, and the browser request lifecycle need real grounding.

What to prioritize first:

JavaScript fundamentals (closures, event loop, this, async model) — everything else builds on this
SQL basics (joins, GROUP BY, primary/foreign keys) — unavoidable for any real project
TypeScript generics and type utilities — required for working in modern codebases
HTTP mechanics (CORS, cookies, request lifecycle) — needed for any web API work
React internals (virtual DOM, reconciliation, controlled components)
System design vocabulary (scaling, caching, load balancing) — lower urgency but needed as you move beyond junior work
